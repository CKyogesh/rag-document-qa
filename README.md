# 📄 Document Q&A RAG System

An AI-powered application that allows users to upload PDF documents and ask questions about them using Retrieval-Augmented Generation (RAG).

## 🚀 Features
- **Private Data Querying:** Ask questions about your own documents securely.
- **Vector Search:** Uses ChromaDB for efficient semantic search.
- **LLM Integration:** Powered by OpenAI GPT-3.5 for accurate answers.
- **Interactive UI:** Built with Streamlit for easy user interaction.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** LangChain, Streamlit
- **Database:** ChromaDB (Vector Store)
- **LLM:** OpenAI API
